# WebchemistCorp Homebrew Tap

Webchemist 도구 모음을 위한 Homebrew tap.

## 설치

```bash
brew tap WebchemistCorp/tap
```

## 도구

### devist

AI 개발 환경을 위한 프로젝트 부트스트랩 CLI.

```bash
brew install devist
```

### asurada

로컬 퍼스트 AI 메모리/인지 데몬.

```bash
brew install asurada
```

### workspace

Webchemist 사업 운영 CLI (자산/구독 관리).

```bash
brew install workspace
```
